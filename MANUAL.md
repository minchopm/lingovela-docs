## Reading a procedure

Read its prerequisites first. Perform the steps in order, then verify the expected result using saved output or observed behavior. If it differs, use the recovery checks and record the smallest reproducible failure. A suggested workflow is not proof of a completed test.

This manual documents public user-facing behavior. It does not disclose private source code, operational configuration or unpublished algorithms. Reviewed 2026-11-04.
