# LingoVela: Live Translate — features and limitations

Use this table to decide whether a workflow fits your task. Product version, device support and active plan can change what is available.

| Capability | What the product documents | Boundary to check |
| --- | --- | --- |
| Conversation | Choose a language for each speaker; translate in both directions with spoken output and text. | Recognition and translation quality vary with language pair, microphone input and background noise. |
| History | Original words, translations and speaker labels; saved conversations are device-local. | Local history does not mean every processing mode is local. Avoid assuming cloud backup or cross-device sync. |
| OpenAI Online | Online translation requests and voice go to OpenAI. | Requires internet, an active subscription and available AI credits. |
| On Device | Compatible downloaded translation models and supported offline speech recognition. | Active subscription still required. Zero AI credits; initial downloads and activation need internet. Language/model availability must be checked. |
| Private Cloud Compute | Public documentation describes text processing by Apple after separate consent, including locally transcribed speech. | Requires internet and credits, compatible iOS 27+ / Apple Intelligence support, and available Apple usage quota. Raw audio/images are not described as uploaded to Apple in this mode. |
| Release and access | The public site currently says App Store release is in preparation; iPhone/iPad iOS 26+ baseline. | Availability is not confirmed by an installation link alone. Mode availability depends on the shipped version and hardware. |

## Before changing a workflow

Keep the source material until you have checked the result. A supported format or visible option does not guarantee that every input will work identically. Test the smallest example that includes the property you care about: text, timing, a formula, a recurring event, metadata or a language pair.

## Pricing and availability

Consult the current app and storefront for local prices, taxes, renewals and entitlements. These guides do not make a fixed regional price or lifetime-availability promise. Product-specific free/paid distinctions are recorded above only where the public materials describe them.
