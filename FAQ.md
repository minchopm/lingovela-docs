# LingoVela: Live Translate — frequently asked questions

## Is LingoVela available now?

At this documentation review, the public site says App Store release is in preparation. Check the official page for a current release announcement; these guides do not assert availability.

## Does zero-credit On Device mean free access?

No. The published plan requires an active subscription for all translation modes. On Device does not spend AI credits, but activation and initial downloads need internet.

## Does Private Cloud Compute work offline?

No. It is an online Apple processing mode with separate compatibility, consent, credit and quota requirements.

## Does a website language selector list supported translation pairs?

Not necessarily. Website localization, app-interface localization, speech recognition and translation-model language support are distinct. Check the actual mode and pair in the installed build.

## Do I need an API key or mandatory sign-in?

The public product description says no user API-key setup and no sign-in; an anonymous device account supports subscription and credit handling.

## How many minutes are included?

Credits meter usage, not a fixed number of conversation minutes. Use the visible balance and current app pricing.

## Are conversations automatically synchronized between devices?

The site describes saved conversations on the device. Do not assume cross-device history synchronization or backup.

## Is LingoVela published by Apple or OpenAI?

No. It is independently published by Arte Soft EOOD.

## Where should I start?

Use the quick-start guide with a small example, verify the saved result, then choose a practical workflow. Avoid beginning with irreplaceable data or an entire production project.

## How do I report a documentation or app problem?

Use the official product support channel for account or purchase issues. A public GitHub issue is suitable for documentation corrections and sanitized reproduction steps. Include the app version, device/OS, expected outcome and actual result; do not attach private data.
