# LingoVela: Live Translate — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Qualify a language pair for travel

### Before you begin

First confirm release availability and a supported installed build. Subscription activation and initial model downloads require internet.

### Steps

1. Select both intended languages in the intended processing mode.

2. Test a question, a reply, a place name, a date and an amount from each speaker.

3. Read the original transcript before evaluating the translated wording; fix recognition errors first.

4. For On Device, repeat with new speech while connectivity is unavailable. Check speech recognition as well as text translation.

5. Record which pair and mode worked, and retain a non-app fallback for important communication.

### Expected result

Both speakers can complete the sample exchange in the actual conditions planned for the trip.

### If the result differs

A localized interface or offline history view does not prove offline speech support. If either direction fails, check compatible models and speech recognition or select another acceptable mode deliberately.

## Procedure 2: Recover a conversation after a misheard name or number

### Before you begin

Keep the original and translated text visible and avoid talking over the current reply.

### Steps

1. Stop adding new sentences when the transcript is clearly wrong.

2. Repeat only the mistaken name or number slowly, using short chunks where helpful.

3. Check the new original transcript, then confirm the translation with the other speaker.

4. Restate the complete short instruction once the key term is correct.

5. End or restart the session if listening has stopped, then verify one simple exchange before resuming.

### Expected result

The corrected detail is understood by both speakers and not buried in a longer ambiguous translation.

### If the result differs

If errors persist, reduce noise and check language selection and the active audio route. For consequential details, confirm against a written source or use qualified interpretation.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
